7.8.3.

ungetc 函数

标准库提供了一个称为 ungetc 的函数，它与第 4 章中编写的函数 ungetch 相比功能更

受限制。

int ungetc(int c, FILE *fp)

该函数将字符 c 写回到文件 fp 中。如果执行成功，则返回 c，否则返回 EOF。每个文件只能

接收一个写回字符。ungetc 函数可以和任何一个输入函数一起使用，比如 scanf、getc 或

getchar。
