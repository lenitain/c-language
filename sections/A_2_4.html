第 A 章

A.2.4 关键宇

下列标识符被保留作为关键字，且不能用于其它用途：

auto

break
case
char
const
continue
default
do
double
else
enum
extern
float
for
goto
if
int
long
register
return
short
signed
sizeof
static
struct
switch
typedef
union
unsigned
void
volatile
while

某些实现还把 fortran 和且 asm 保留为关键字。

说明：关键字 const、signed 和 volatile 是 ANSI 标准中新增加的；enum 和 void是第 1 版后新增加的，现已被广泛应用；entry 曾经被保留为关键字但从未被使用过，现在已经不是了。
