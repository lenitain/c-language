2.8 自增运算符与自减运算符

C 语言提供了两个用于变量递增与递减的特殊运算符。自增运算符++使其操作数递增 1，

自减运算符使其操作数递减 1。我们经常使用++运算符递增变量的值，如下所示：

if (c = '\n')

++nl;

++与--这两个运算符特殊的地方主要表现在：它们既可以用作前缀运算符（用在变量前

面，如++n）

。也可以用作后缀运算符（用在变量后面，如 n++）。在这两种情况下，其效果都

是将变量 n 的值加 1。但是，它们之间有一点不同。表达式++n 先将 n 的值递增 1，然后再使

用变量 n 的值，而表达式 n++则是先使用变量 n 的值，然后再将 n 的值递增 1。也就是说，

对于使用变量 n 的值的上下文来说，++n 和 n++的效果是不同的。如果 n 的值为 5，那么

x = n++;

执行后的结果是将 x 的值置为 5，而

x = ++n;

将 x 的值置为 6。这两条语句执行完成后，变量 n 的值都是 6。自增与自减运算符只能作用于

变量，类似于表达式(i+j)++是非法的。

在不需要使用任何具体值且仅需要递增变量的情况下，前缀方式和后缀方式的效果相同。

例如：

if (c == '\n')

nl++;
